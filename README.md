# Lightfern Homebrew Tap

Homebrew casks for [Lightfern](https://lightfern.com/).

## Install

```sh
brew install --cask lightfern/tap/lightfern
```

For the beta:

```sh
brew install --cask lightfern/tap/lightfern@beta
```

The beta cask installs the same app on the production update channel. To keep getting betas, open **Settings → Updates → Update channel** and choose **Beta**.

The two casks conflict, so uninstall one before installing the other.
